CORE BEHAVIOR
States Aligned → Drifting (past threshold) → Slouch (sustained).
Sensitivity Relaxed 22° · Balanced 15° · Strict 8° (Settings).

Calibrate 5-second still hold captures baseline; re-runnable from Settings.
Edge IMU unavailable / BT off / non-Pro buds → Disconnected; never show stale data.
